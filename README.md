# TENacious AI

Hackathon project for team #hack-team-10, Aberdeen Advisors.

## The challenge

> Aberdeen has strong client relationships and deep experience, but business development often depends on individual networks, manual research, and inconsistent follow-up. Build an internal AI-powered tool that identifies high-potential accounts, detects relevant buying signals, maps decision-makers and Aberdeen relationships, recommends the most relevant offerings and credentials, and generates tailored outreach for partners and pursuit teams.

## What's in this repo

This repo currently holds the source documents and agent instructions the project is being
built from. There is no application code yet.

| Folder | Contents |
|---|---|
| [`agent-instructions/`](agent-instructions) | The three instruction files that drive the pursuit-intelligence agent — its step-by-step process, the Aberdeen brand and document system, and the offering taxonomy and credential inventory. |
| [`client-data/`](client-data) | Publicly published company financial documents — Q2 2026 earnings releases and press releases — used as realistic sample data. |
